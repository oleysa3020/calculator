# Конвертер валют и Кредитный калькулятор

## Описание проекта

Это десктопное приложение, разработанное на Python с использованием библиотеки `tkinter`. 
Программа выполняет две основные функции:
1. **Кредитный калькулятор:** рассчитывает ежемесячный аннуитетный платеж, общую сумму выплат и размер переплаты по кредиту.
2. **Конвертер валют:** конвертирует сумму в рублях в выбранную иностранную валюту (USD, EUR, GBP, CNY) по актуальному курсу Центробанка РФ.
   
Все действия программы логируются в специальном окне, а курсы валют сохраняются в локальную базу данных.

## Используемые технологии

*   **Язык программирования:** Python 3.10+
*   **Графический интерфейс:** `tkinter` (встроенная библиотека Python)
*   **База данных:** `SQLite3` (встроенная библиотека Python) — для хранения курсов валют.
*   **Работа с сетью:** библиотека `requests` — для получения актуальных курсов с API ЦБ РФ (https://www.cbr-xml-daily.ru/).

## Как запустить проект

Для запуска приложения вам понадобится установленный Python (версии 3.8 или выше).

1. **Клонируйте репозиторий** или скачайте файлы проекта:
   ```bash
   git clone https://github.com/oleysa3020/calculator.git
   cd <название_папки_проекта>
   
2. **Установите зависимости** (библиотеку requests):
```bash
pip install requests
```

3. **Запустите приложение:**
```bash
python main.py
```
